# GitHub upload checklist

Before submitting the revised manuscript:

- Replace `[GITHUB REPOSITORY URL]` in the manuscript Data Availability statement with the final public repository URL.
- Upload all files in this repository.
- Confirm that the repository is public and accessible without requesting permission.
- Confirm that the 68-paper dataset contains exactly 68 unique study IDs.
- Confirm that Table A3 contains 68 rows and matches the manuscript.
- Confirm that Figures 6 and 7 use the paper-level counting files included here.
- Confirm that Figure 10 uses arXiv subject classes and does not retain Scopus ASJC labeling.
- Add the original VOSviewer project files (`.vos`, if available) if you still have them; these preserve the exact original layout, clusters, and visualization settings.
- Do not upload copyrighted research-paper PDFs unless redistribution rights permit it.
